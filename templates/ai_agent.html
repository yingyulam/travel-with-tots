API key setup

This agent calls OpenRouter, the same provider the chatbot and AI planner already use.

  1. Sign up (free) at openrouter.ai.
  2. Open openrouter.ai/keys, click Create Key, and copy the value -- it's only shown once.
  3. Paste it into .env as OPENROUTER_API_KEY=<your key> (copy .env.example to .env first if you haven't already).
  4. The default free model needs no added credit; switching to a paid model does, under openrouter.ai/settings/credits.

Never paste a real key into chat, a screenshot, or a commit -- the key is only ever read from .env via os.environ, never logged or printed.
