Test page for the AI Agent. It has no chat of its own on purpose: use the bubble in the corner, which is the agent, and this panel shows what it did. ← Back to Components

The bubble is the agent's interface, so what you test here is what a parent gets. Its model dropdown picks the agent's model, which makes this the place to check whether a given model can call tools at all. Ask a question about the site and the agent should use its knowledge-base tool; describe a day out and it should use the form extractor.

API key setup

This agent calls OpenRouter, the same provider the AI planner already uses.

  1. Sign up (free) at openrouter.ai.
  2. Open openrouter.ai/keys, click Create Key, and copy the value -- it's only shown once.
  3. Paste it into .env as OPENROUTER_API_KEY=<your key> (copy .env.example to .env first if you haven't already).
  4. The free models need no added credit; a paid one does, under openrouter.ai/settings/credits.

Never paste a real key into chat, a screenshot, or a commit -- the key is only ever read from .env via os.environ, never logged or printed.
