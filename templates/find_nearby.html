API key setup

Your browser supplies the coordinates for free (no key needed). The key is only used server-side, to turn those coordinates into a city and neighbourhood.

  1. Open the Google Cloud console and create (or pick) a project.
  2. Enable the Geocoding API. That single API is all this component uses.
  3. Under Credentials, create an API key, then restrict it: API restrictions to the Geocoding API only, and Application restrictions to IP addresses.
  4. Paste it below and click Save Key.

Google gives a recurring monthly credit that covers well beyond this app's usage, but the Geocoding API does require billing to be enabled on the project. Restrict the key as above so a leak can't be used elsewhere. The key is only ever read from .env via os.environ, never logged, printed, or sent to the browser.
