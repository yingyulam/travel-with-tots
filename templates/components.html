🔴 Tools

Plan trips (adjustment)

AI-backed

src/components/plan_trip.py: a rule-based draft, then PlanningAgent.adjust_plan() smooths it -- a genuine judgment call, not something rules alone can decide. Used by both /plan and the AI Agent's tool.

Try it

Replan a trip on-the-go (adjustment)

AI-backed

src/components/replan_trip.py: same pattern as Plan trips, for a mid-trip situation. Used by the /trip page's replan flow.

Try it

Find nearby stops

deterministic

src/components/find_nearby.py: narrows the curated venues to your resolved city and neighbourhood, then matches your need (restaurant, nursing room, quiet spot...) using the same interactions.find_nearby() the trip page already used. Falls back to a live web search when the curated table has nothing. Intentionally not AI, since there's no judgment call to make.

Try it

Look up saved plans

deterministic

The dashboard and saved-trip pages read straight from the database -- not something the AI agent invokes itself.

Web Search

API-backed

Live results from the Tavily Search API (src/components/search_web.py). Not yet wired in as a fallback for the venue DB, just its own standalone test page for now.

Try it

Google Map handoff

API-backed

src/components/geocode.py: turns browser coordinates (or a typed address) into a city and neighbourhood via the Google Geocoding API, so "find a place near us" knows where "us" is. The key stays server-side; the browser only uses its own free geolocation. Travel-time routing and the accommodation field are still to come.
