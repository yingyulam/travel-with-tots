API key setup

This component calls the Tavily Search API.

  1. Sign up (free) at tavily.com -- no credit card required.
  2. Open your dashboard and copy your API key.
  3. Paste it below and click Save Key.

The free plan includes 1,000 search credits per month, resetting monthly; requests simply stop once exhausted rather than billing you. The key is only ever read from .env via os.environ, never logged or printed.
